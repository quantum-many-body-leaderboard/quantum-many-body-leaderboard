                   Accurate simulations of strongly correlated electrons remain a central challenge in computational
                physics. We introduce neural-network Gaussian projected entangled-pair states (NN-GPEPS), which
                exploit the locally-entangled subspace of Gaussian states to give an architecture more compatible
                with modern neural networks and an exact contraction cost ofO(N          3/2   ) on two-dimensional lattices.
                For  the  Hubbard  model  atU/t=  8  and  1/8  hole  doping,  we  obtain  state-of-the-art  variational
                energies in large lattices of up to 1024 sites.  These results demonstrate an accurate approach to
                strongly correlated fermions by connecting neural networks with Gaussian tensor networks.

   We generate the Gaussian site matrices with a real-valued residual CNN [32] (Fig.B1).  A learned embedding maps
each local occupation state to aC-dimensional feature vector,  with the same embedding table used at every site.
These features then pass through a sequence ofn    b  pre-activation residual blocks [33] built from 3×3 convolutions

GELU nonlinearities [35] before each convolution [Fig.B1(b)].
   The  features  are  rescaled  by  1/ √nb + 1  before  an  affine  1×1  head  maps  them  to  the  strict  upper  triangle  of

Antisymmetry determines the remaining entries.  The network settings are listed in TableB1.
   We initialize the embedding table with standard normal entries, use LeCun normal initialization [36] for convolution
weights, and set all biases to zero.  The last convolution of every residual block is additionally scaled by 0.1 (N     v = 3)
or 0.02 (N     v  = 4) at initialization, so that each block starts close to the identity map.  All learned maps are shared
across sites, so the parameter count is independent of lattice size and the same weights can be transferred between
periodic lattices.

                                               Appendix D: Optimization and measurements
                                                          1.    Sampling and optimization
   We use the mixed Metropolis sampler implemented in Quantax [17], with equal probabilities for nearest-neighbor
electron hops and site exchanges.  Each update uses 8192 configurations in a fixed (N ↑, N↓) sector, separated by 4N
proposals per chain.  Sampling follows the squared amplitude of the wavefunction being optimized.
   We optimize the network with the Quantax implementation of AdamSR [17], with first- and second-moment decay
factorsµ= 0.95 andβ= 0.995, respectively.  The associated least-squares problems are solved using an adaptation of
Quantax’s LSMR solver [17,18] with relative tolerance 10         −4  , absolute tolerance 0 and at most 500 iterations, without
an explicit diagonal shift.  Local energies entering the gradient are clipped to the sampled mean±5σ, whereσis their
sampled standard deviation [20].
   We constrain the Euclidean norm of each parameter update [20]. At iterationt, the proposed update ∆θ                           t is rescaled
as

The norm bound remains atC    0 until iterationt                 0, then decreases on the scaleT.  Updates whose norms lie below this
bound are unchanged.  A typical setting isC   0 = 0.5,t       0 = 1000 andT= 1500, with tighter norm bounds and adjusted
schedules for continued and projected optimization.
